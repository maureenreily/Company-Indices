Technology Industry ESG Index

Overview
This branch contains a hypothetical ESG (Environmental, Social, Governance) index dataset specifically for the Technology industry. This dataset serves as a sample for ESG analysis and includes weighted ESG scores inspired by methodologies from Bloomberg and S&P ESG frameworks. 

Files in This Branch
- **[Tech Industry Index Documentation](TechIndustryIndex.md): The main dataset file containing fictional company data in the Technology sector with detailed ESG metrics.
- **Index Weights**: Environmental, Social, and Governance components are weighted by industry significance, making this data adaptable across technology-related ESG analyses.

Dataset Structure
The dataset includes the following columns:

- **Company Name**: The fictional company name.
- **Headquarters**: Location of the company’s headquarters.
- **Zip Code**: The zip code for the headquarters.
- **Year of Report**: The reporting year for the data.
- **Industry**: Set as "Technology" for all companies.
- **ESG Score**: The calculated overall ESG score.
- **Environmental**: The company's environmental performance score.
- **Social**: The company's social responsibility score.
- **Governance**: The company's governance score.
- **Price Index**: Hypothetical stock price index for each company.
- **Sustainability Goals**: Key environmental and social goals set by the company.
- **Key Achievements**: Major ESG achievements of the company.
- **Stakeholder Engagement**: Description of stakeholder engagement activities.
- **Environmental Weight**: Weight assigned to environmental factors in the ESG score.
- **Social Weight**: Weight assigned to social responsibility factors.
- **Governance Weight**: Weight assigned to governance practices.

Methodology
The ESG score for each company in this dataset is calculated using a weighted sum of the Environmental, Social, and Governance scores:
  - **Environmental Weight**: 0.4
  - **Social Weight**: 0.3
  - **Governance Weight**: 0.3

These weights reflect the tech industry’s specific ESG priorities, balancing environmental and governance concerns with social responsibility. This structure also makes the dataset adaptable to further analysis and comparison across other industries.

How to Use This Data
1. Clone this branch to access the ESG dataset.
2. Explore and analyze the data using any data analysis tool, such as Python or Excel, to calculate the impacts of different weights, compare companies, or simulate how adjustments in ESG practices could affect overall scores.

Future Goals
